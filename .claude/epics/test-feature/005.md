# Task: Database Detail Page

## Description

Create a detailed view page for individual databases showing comprehensive metrics including table listings, historical size trends, connection information, and database configuration. This page is accessible by clicking a database card from the dashboard.

## Acceptance Criteria

- [ ] Database detail route configured (`/database/:name`)
- [ ] Header section shows: DB version, collation, connection limit
- [ ] Table listing displays: table name, type, row count, size
- [ ] Line chart shows database size trend over last 7 days
- [ ] Chart.js integrated and rendering correctly
- [ ] Navigation back to dashboard works
- [ ] Real-time data fetching with TanStack Query
- [ ] Mobile-responsive layout
- [ ] Empty state shown when no historical data available

## Technical Details

**Implementation Approach:**

1. Route Configuration:
   ```typescript
   // src/App.tsx
   import { BrowserRouter, Routes, Route } from 'react-router-dom';

   <Routes>
     <Route path="/" element={<Dashboard />} />
     <Route path="/database/:name" element={<DatabaseDetail />} />
   </Routes>
   ```

2. Database Detail Page:
   ```typescript
   // src/pages/DatabaseDetail.tsx
   export const DatabaseDetail: React.FC = () => {
     const { name } = useParams<{ name: string }>();

     const { data: details } = useQuery({
       queryKey: ['database', name],
       queryFn: () => fetchDatabaseDetails(name)
     });

     const { data: metrics } = useQuery({
       queryKey: ['metrics', name],
       queryFn: () => fetchMetricsHistory(name)
     });

     return (
       <div className="container mx-auto p-4">
         <BackButton />
         <DatabaseHeader {...details} />
         <MetricChart data={metrics} />
         <TableListing tables={details?.tables} />
       </div>
     );
   };
   ```

3. Metrics Chart Component:
   ```typescript
   // src/components/MetricChart.tsx
   import { Line } from 'react-chartjs-2';

   export const MetricChart: React.FC<{ data: MetricData[] }> = ({ data }) => {
     const chartData = {
       labels: data.map(d => d.timestamp),
       datasets: [{
         label: 'Database Size (MB)',
         data: data.map(d => d.value / 1024 / 1024),
         borderColor: 'rgb(75, 192, 192)',
       }]
     };

     return <Line data={chartData} options={chartOptions} />;
   };
   ```

4. Table Listing Component:
   ```typescript
   // src/components/TableListing.tsx
   export const TableListing: React.FC<{ tables: Table[] }> = ({ tables }) => (
     <table className="w-full border-collapse">
       <thead>
         <tr className="bg-gray-100">
           <th>Table Name</th>
           <th>Type</th>
           <th>Rows</th>
           <th>Size</th>
         </tr>
       </thead>
       <tbody>
         {tables?.map(table => (
           <tr key={table.name}>
             <td>{table.name}</td>
             <td>{table.type}</td>
             <td>{table.row_count?.toLocaleString()}</td>
             <td>{table.size}</td>
           </tr>
         ))}
       </tbody>
     </table>
   );
   ```
