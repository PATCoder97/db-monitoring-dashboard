# Task: Frontend Dashboard Overview

## Description

Build the main dashboard page showing all monitored databases in a grid layout with health status indicators, search/filter functionality, and auto-refresh capabilities using React, TypeScript, and Tailwind CSS.

## Acceptance Criteria

- [ ] React app created with TypeScript template
- [ ] Tailwind CSS configured and working
- [ ] Dashboard Overview page (`/`) displays all databases
- [ ] DatabaseCard component shows: name, size, table count, status badge
- [ ] StatusBadge component with color coding (green/yellow/red)
- [ ] Search bar filters databases by name
- [ ] Auto-refresh toggle (30s interval, on by default)
- [ ] TanStack Query configured for API data fetching
- [ ] Mobile responsive (1 column on mobile, 3 columns on desktop)
- [ ] Loading states and error handling implemented

## Technical Details

**Implementation Approach:**

1. Project Setup:
   ```bash
   npx create-react-app frontend --template typescript
   cd frontend
   npm install @tanstack/react-query axios tailwindcss chart.js
   npx tailwindcss init
   ```

2. API Client:
   ```typescript
   // src/api/client.ts
   import axios from 'axios';

   export const api = axios.create({
     baseURL: 'http://localhost:8000/api'
   });

   export const fetchDatabases = async () => {
     const { data } = await api.get('/databases');
     return data;
   };
   ```

3. Database Card Component:
   ```typescript
   // src/components/DatabaseCard.tsx
   interface DatabaseCardProps {
     name: string;
     size: string;
     tableCount: number;
     status: 'ok' | 'warning' | 'error';
   }

   export const DatabaseCard: React.FC<DatabaseCardProps> = ({
     name, size, tableCount, status
   }) => (
     <div className="p-4 border rounded-lg shadow hover:shadow-lg">
       <StatusBadge status={status} />
       <h3 className="text-xl font-bold">{name}</h3>
       <p>Size: {size}</p>
       <p>Tables: {tableCount}</p>
     </div>
   );
   ```

4. Dashboard Page:

