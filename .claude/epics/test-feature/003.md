# Task: API Error Handling & Security

## Description

Implement comprehensive error handling, input validation, and security measures for the FastAPI backend. This includes connection timeouts, proper error responses, credential management via environment variables, and request validation.

## Acceptance Criteria

- [ ] All API endpoints have try-catch error handling
- [ ] Database connection timeouts set to 5 seconds
- [ ] Proper HTTP status codes returned (400, 404, 500, 503)
- [ ] Input validation for database names (alphanumeric, underscore, dash only)
- [ ] Environment variables used for all database credentials
- [ ] `.env.example` file created with all required variables
- [ ] Rate limiting implemented (100 requests/minute per IP)
- [ ] Security headers added (CORS, Content-Security-Policy)

## Technical Details

**Implementation Approach:**

1. Error Handling Middleware:
   ```python
   @app.exception_handler(Exception)
   async def global_exception_handler(request, exc):
       logger.error(f"Unhandled exception: {exc}")
       return JSONResponse(
           status_code=500,
           content={"error": "Internal server error"}
       )
   ```

2. Database Timeout Configuration:
   ```python
   connection = psycopg2.connect(
       **conn_params,
       connect_timeout=5,
       options="-c statement_timeout=5000"
   )
   ```

3. Input Validation:
   ```python
   from pydantic import BaseModel, validator

   class DatabaseRequest(BaseModel):
       name: str

       @validator('name')
       def validate_name(cls, v):
           if not re.match(r'^[a-zA-Z0-9_-]+$', v):
               raise ValueError('Invalid database name')
           return v
   ```

4. Environment Configuration:
   ```python
   # config/settings.py
   from pydantic import BaseSettings

   class Settings(BaseSettings):
       postgres_host: str
       postgres_port: int
       db_password_casaos: str
       metrics_retention_days: int = 90

       class Config:
           env_file = ".env"
   ```

5. Rate Limiting:
   ```python
   from slowapi import Limiter
   from slowapi.util import get_remote_address

   limiter = Limiter(key_func=get_remote_address)
   app.state.limiter = limiter

   @app.get("/api/databases")
   @limiter.limit("100/minute")
   async def list_databases():
       pass
   ```
