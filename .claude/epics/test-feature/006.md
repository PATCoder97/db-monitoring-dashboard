# Task: Data Export & Configuration

## Description

Implement CSV/JSON export functionality for current metrics and create a configuration page to view database connections. Backend generates export files server-side, frontend provides download buttons.

## Acceptance Criteria

- [ ] Backend endpoint `GET /api/export/csv` returns CSV file
- [ ] Backend endpoint `GET /api/export/json` returns JSON file
- [ ] Export includes all current database metrics
- [ ] Frontend export button triggers download
- [ ] Configuration page shows list of monitored databases
- [ ] Configuration page displays connection settings (host, port - no passwords)
- [ ] Export completes within 3 seconds
- [ ] CSV format is valid (opens in Excel/Google Sheets)

## Technical Details

**Implementation Approach:**

1. Backend CSV Export:
   ```python
   # app/routers/export.py
   from fastapi.responses import StreamingResponse
   import csv, io

   @router.get("/api/export/csv")
   async def export_csv():
       output = io.StringIO()
       writer = csv.writer(output)
       writer.writerow(['Database', 'Size', 'Tables', 'Status'])

       databases = await db_client.list_all_databases()
       for db in databases:
           writer.writerow([db['name'], db['size'], db['table_count'], db['status']])

       output.seek(0)
       return StreamingResponse(
           iter([output.getvalue()]),
           media_type="text/csv",
           headers={"Content-Disposition": "attachment; filename=databases.csv"}
       )
   ```

2. Backend JSON Export:
   ```python
   @router.get("/api/export/json")
   async def export_json():
       databases = await db_client.list_all_databases()
       return JSONResponse(
           content={"exported_at": datetime.now().isoformat(), "databases": databases},
           headers={"Content-Disposition": "attachment; filename=databases.json"}
       )
   ```

3. Frontend Export Button:
   ```typescript
   // src/components/ExportButton.tsx
   export const ExportButton: React.FC<{ format: 'csv' | 'json' }> = ({ format }) => {
     const handleExport = async () => {
       const response = await api.get(`/export/${format}`, { responseType: 'blob' });
       const url = window.URL.createObjectURL(new Blob([response.data]));
       const link = document.createElement('a');
       link.href = url;
       link.download = `databases.${format}`;
       link.click();
     };

     return (
       <button onClick={handleExport} className="btn btn-primary">
         Export {format.toUpperCase()}
       </button>
     );
   };
   ```
