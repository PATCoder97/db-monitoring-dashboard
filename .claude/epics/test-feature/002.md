# Task: Metrics Storage & Scheduler

## Description

Implement historical metrics collection and storage by creating a PostgreSQL table to store database metrics over time, and set up a background scheduler to collect metrics every 5 minutes. This enables trend analysis and capacity planning features.

## Acceptance Criteria

- [ ] `metrics_history` table created in PostgreSQL with proper schema
- [ ] SQL migration script created for table setup
- [ ] Background scheduler configured using APScheduler
- [ ] Metrics collection job runs every 5 minutes
- [ ] Data retention policy implemented (deletes data older than 90 days)
- [ ] API endpoint `GET /api/metrics/history/{db_name}` returns historical data
- [ ] Metrics successfully stored for all monitored databases

## Technical Details

**Implementation Approach:**

1. Database Schema:
   ```sql
   CREATE TABLE metrics_history (
       id SERIAL PRIMARY KEY,
       timestamp TIMESTAMPTZ NOT NULL DEFAULT NOW(),
       db_name VARCHAR(255) NOT NULL,
       metric_type VARCHAR(50) NOT NULL,  -- 'size', 'table_count', 'connections'
       value NUMERIC NOT NULL,
       metadata JSONB,
       INDEX idx_timestamp (timestamp),
       INDEX idx_db_name (db_name)
   );
   ```

2. Metrics Collection Service:
   ```python
   # app/services/metrics_collector.py
   async def collect_metrics():
       databases = await db_client.list_all_databases()
       for db in databases:
           await store_metric(
               db_name=db['name'],
               metric_type='size',
               value=parse_size(db['size'])
           )
   ```

3. APScheduler Setup:
   ```python
   from apscheduler.schedulers.asyncio import AsyncIOScheduler

   scheduler = AsyncIOScheduler()
   scheduler.add_job(collect_metrics, 'interval', minutes=5)
   scheduler.start()
   ```

4. Retention Policy:
   ```python
   async def cleanup_old_metrics():
       query = "DELETE FROM metrics_history WHERE timestamp < NOW() - INTERVAL '90 days'"
       await execute(query)
   ```
